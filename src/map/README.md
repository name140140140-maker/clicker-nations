# Карта територій

Компонент: `src/TerritoryMap.jsx` (MapLibre). Модель областей: `src/map/regionsModel.js`.

## Що показує карта
Лише **адміністративні області** й їхні кордони — без реальних держав і прапорів. Три типи територій:

| Тип | Вигляд |
|---|---|
| Вільні | нейтральний сіро-зелений колір, ніхто не контролює |
| Зайняті | колір країни, яка володіє областю (колір обирає лідер) |
| Власні | колір твоєї країни + біла рамка по зовнішньому краю території |

Кордон між областями різних власників — товстіша лінія, між областями одного власника — тонка (з'являється при наближенні).

## Дані
* Геометрія: `public/data/world-topology.json` (3224 області, у кожної унікальний `cn_region_id`).
  Оновити: `npm run fetch:regions` → `npm run build:topology`.
* Країни й володіння — Supabase, таблиця `kv_store` (див. `src/nations.js`):
  * `country:<id>` — `{ id, name, color, leaderId, createdAt, regionIds }`
  * `terr:<cn_region_id>` — id країни-власника. Запис створюється атомарно (`insert`, перший виграє),
    тому дві людини не можуть одночасно зайняти одну вільну область.

## Як працює оновлення
Власник і колір області — це `feature-state` MapLibre (`o`, `c`), а для кордонів — власники двох сусідніх
областей (`oa`, `ob`). Виразів шарів після створення ми не змінюємо (зміна data-driven виразу перебудовує
плитки всього джерела — важко на телефонах), тому нова країна чи зміна кольору оновлює лише кілька областей.

## Режими
* `mode="view"` — вкладка «Карта»: клік по області показує, кому вона належить; камера наближається до твоєї країни.
* `mode="pick"` — онбординг «Створити країну»: можна вибрати лише вільну область.
