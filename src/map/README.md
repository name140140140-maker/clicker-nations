# Карта територій

Компонент: `src/TerritoryMap.jsx` (MapLibre). Модель областей: `src/map/regionsModel.js`.

## Що показує карта
Лише **адміністративні області** й їхні кордони — без реальних держав і прапорів. Три типи територій:

| Тип | Вигляд |
|---|---|
| Вільні | зелений колір із текстурою трави, ніхто не контролює |
| Зайняті | колір країни, яка володіє областю (колір обирає лідер), із ледь помітною текстурою |
| Власні | колір твоєї країни + біла рамка по зовнішньому краю території |

Кордон між областями різних власників — товстіша лінія, між областями одного власника — тонка (з'являється при наближенні).
Море синє з процедурною текстурою хвиль. Текстури генеруються в `src/map/textures.js`; завантаження карти
чекає на перше малювання областей, а геометрія обрізає широту до межі проєкції Меркатора (±85.05°).
Міста розбиті на сім рівнів за населенням і статусом столиці та плавно з'являються/зникають при масштабуванні.

## Дані
* Геометрія: `public/data/world-topology.json` (3224 області, у кожної унікальний `cn_region_id`).
  Оновити: `npm run fetch:regions` → `npm run build:topology`.
* Країни й володіння — Supabase, таблиця `kv_store` (див. `src/nations.js`):
  * `country:<id>` — `{ id, name, color, leaderId, createdAt, regionIds }`
  * `terr:<cn_region_id>` — id країни-власника. Запис створюється атомарно (`insert`, перший виграє),
    тому дві людини не можуть одночасно зайняти одну вільну область.

## Як працює оновлення
Власник і колір області — це `feature-state` MapLibre (`o`, `c`), а для кордонів — власники двох сусідніх
областей (`oa`, `ob`). Виразів шарів після створення ми не змінюємо (зміна data-driven виразу перебудовує
плитки всього джерела — важко на телефонах), тому нова країна чи зміна кольору оновлює лише кілька областей.

## Режими
* `mode="view"` — вкладка «Карта»: клік по області показує, кому вона належить; камера наближається до твоєї країни.
* `mode="pick"` — онбординг «Створити країну»: можна вибрати лише вільну область.

## Міста (реальні назви)
* Файл `public/data/cities.json` будує `scripts/build-cities.mjs` з Natural Earth «populated places»
  (суспільне надбання). Кожне місто прив'язується до області карти; якщо в області немає жодного міста,
  ставиться одна точка з назвою області (`fallback`).
  * `npm run build:cities` — завантажує набір з GitHub (потрібен інтернет);
  * `npm run build:cities -- шлях/до/ne_10m_populated_places.geojson` — із власного файлу;
  * повний набір `ne_10m_populated_places.geojson` містить українські назви (`name_uk`).
  * У репозиторії лежить повний набір Natural Earth; запасна точка з назвою області додається лише там,
    де в конкретній області немає міста в наборі.
* Важливість міста 0–100 — логарифм населення (+ бонус столиці), див. `src/map/cities.js`.
* Зони міст: діаграма Вороного, обрізана межами області (`src/map/geo.js`). Малюються для вибраної області
  як прев'ю майбутніх ліній фронту.
* Підписи міст використовують шрифти Noto Sans Protomaps (`GLYPHS_URL` у `TerritoryMap.jsx`).
  Для незалежності від зовнішнього сервера скопіюй шрифти в `public/fonts/` і заміни URL на `/fonts/{fontstack}/{range}.pbf`.
