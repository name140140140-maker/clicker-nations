# Карта світу (MapLibre): живі кордони, прапори, продуктивність

Компонент: `src/WorldMapGL.jsx`. Допоміжні модулі — тут, вони не залежать від React/MapLibre
(крім `flagOverlay.js`, який працює з об'єктом карти).

| Файл | Що робить |
|---|---|
| `territory.js` | Модель територій: декодована топологія, **поточні власники областей**, шматки суші (материк/острів/ексклав) кожного власника, GeoJSON одразу як текст |
| `regionMatch.js`, `regionOverrides.js` | Зіставлення назв областей з гри (`REGION_DATA`) з полігонами карти (ключі `cityControl` = `ISO\|назва з гри`) |
| `flagAssets.js`, `flagIdMap.js` | Прапори: відновлення втрачених `id`, коректна SVG-обгортка, векторне малювання, нестандартні форми (Непал) |
| `flagOverlay.js` | Шар прапорів: запікання видимої частини під поточний zoom, LOD штампів, логіка островів, значки |

## Живі кордони
Кордон — це **спільна арка топології** між двома областями. Вона вважається державним кордоном, коли поточні
власники цих областей різні. Тому після захоплення (наприклад, Україна → Курська область) область отримує
прапор і колір нового власника, лінія фронту зсувається, а межа всередині нової держави стає внутрішньою.
Реалізовано через `feature-state` (`setFeatureState`): оновлюються лише змінені області й їхні арки — без
перезавантаження стилю чи плиток. Клік по області вибирає **поточного** власника; контур вибраної країни
малюється за її поточною територією. Подію захоплення (`onCapture`) і спалах отримують лише змінені області.

## Прапори
* Усі 241 прапор вантажаться: стара обгортка не мала `xmlns:xlink`, тож 55 прапорів із `xlink:href`
  (Аргентина, Мексика, Китай, Індія, Кенія…) просто не завантажувались.
* У даних були вирізані `id` (`<use href="#cn-a">` без цілі) — у Китаю зникли зірки тощо. `flagIdMap.js`
  повертає їх (одноразово згенеровано за порядком посилань; для Аргентини — вручну).
* Малюємо з вектора: `flagOverlay.js` запікає лише видиму область (+12% запасу) у роздільності екрана
  після кожного `moveend`; між запіканнями MapLibre рухає поточну текстуру разом із картою.
* **Нестандартна форма** (Непал): форма визначається автоматично за прозорістю (`coverage < 0.8`); такий
  прапор вписується цілком, решта території заливається кольором поля (`FLAG_SHAPE_OVERRIDES` у
  `flagAssets.js` — точкове налаштування для будь-якої країни).
* **LOD штампів** (`stampLayout`): один прапор покриває територію, поки він ≤ ~360 px; далі ділиться навпіл
  (2×2, 4×4…), тому прапор великої країни не роздувається, а маленької — не зникає (значок-прапорець).
* **Острови** (`partMode`): великі острови поряд із материком — без окремого прапора; середні — залежно від
  розміру на екрані й відстані; дрібні далекі — значок (≤3 на власника, ≤80 загалом).
  Порогові значення — константи на початку `flagOverlay.js` і `territory.js` (`PART_BIG_KM2`, `PART_MEDIUM_KM2`).

## Продуктивність
GeoJSON збирається текстом і передається воркеру як Blob (без величезного проміжного об'єкта); усе розбито
на пачки з поверненням кадру; важкі дані кешуються між заходами на екран; максимальний zoom 14 (джерела
мають `maxzoom: 10`, вище плитки розтягуються); `antialias` вимкнено на екранах із DPR ≥ 2.

## Перевірка даних
`npm run audit:map` — прапори ↔ ISO ↔ країни/області гри, незакриті посилання в SVG, частка областей гри,
прив'язаних до полігонів (зараз ≈75%: у геометрії грубіший поділ, ніж у грі, наприклад Уганда — 136 районів
у грі проти 4 областей на карті; для них захоплення не можна показати на рівні області).
