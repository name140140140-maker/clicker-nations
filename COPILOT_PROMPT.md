# Промпт для Copilot (виконати в Codespaces)

Скопіюй усе нижче в Copilot Chat (agent mode):

---
Мені потрібно накотити готову переробку гри в мій репозиторій. Архів `clicker-nations-rework.zip` лежить у корені Codespace (завантаж його в Codespace, якщо ще ні).

Виконай по порядку, нічого не пропускай і не вигадуй:

1. Розпакуй архів ПОЗА репозиторієм: `mkdir -p ~/rework && unzip -o clicker-nations-rework.zip -d ~/rework`.
2. Скопіюй вміст розпакованої папки в корінь проєкту (`rsync -a --exclude .git --exclude node_modules --exclude .env --exclude public/data/cities.json ~/rework/ ./`). НЕ чіпай `.git`, `node_modules`, `.env` і `public/data/cities.json` (лише читання, ніколи не змінювати).
3. Перевір, що `public/data/cities.json` не змінився: `git status --short public/data/cities.json` має бути порожнім.
4. Перевір, що в `api/` рівно 12 файлів `.js` без префікса `_`: `ls api/*.js | grep -v '/_' | wc -l` → 12. Якщо інше число — зупинись і повідом.
5. `npm install`
6. `npm test` — усі тести мають пройти (очікується 35).
7. `npm run build` — збірка без помилок. Покажи мені таблицю розмірів чанків із виводу Vite (особливо головний `index-*.js` і чанк карти).
8. Якщо build або test впали — НЕ виправляй наосліп: покажи повний текст помилки й зупинись.
9. Якщо все зелене: `git add -A && git commit -m "Переробка: мультяшна планета, нове ядро кліка, єдиний планувальник, lite-карта, агрегований знімок гравців" && git push`.
10. Надішли мені: вивід тестів, таблицю чанків, `git status`, результат push.
11. Окремо, нічого не змінюючи: запусти `npx depcheck` (або `npm ls --depth=0`) і лише перелічи залежності, які виглядають невикористаними, щоб я вирішив, що видаляти.
