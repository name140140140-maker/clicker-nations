# Clicker Nations — публікація як Telegram Mini App

Тобі НЕ треба нічого встановлювати на комп'ютер. Все робиться через сайти в браузері.

## Крок 1. Виклади код на GitHub
1. Зареєструйся на https://github.com (безкоштовно)
2. Натисни "New repository" → назви його, наприклад `clicker-nations` → Create repository
3. На сторінці репозиторію натисни "uploading an existing file" і перетягни туди ВСІ файли з цієї папки (зберігаючи структуру папок `src/`)
4. Натисни "Commit changes"

## Крок 2. Розгорни сайт на Vercel (безкоштовно, автоматично)
1. Зайди на https://vercel.com і увійди через свій GitHub-акаунт
2. Натисни "Add New" → "Project"
3. Обери свій репозиторій `clicker-nations` → Import
4. Нічого не змінюй в налаштуваннях — Vercel сам розпізнає Vite-проєкт
5. Натисни "Deploy" і почекай 1-2 хвилини
6. Отримаєш посилання типу `https://clicker-nations-xxxx.vercel.app` — це твій сайт з грою, вже на HTTPS

## Крок 3. Створи Telegram-бота
1. Відкрий в Telegram бота @BotFather
2. Напиши `/newbot`, дай імʼя і юзернейм боту
3. Він надішле тобі токен — збережи його (не показуй нікому)

## Крок 4. Приєднай гру до бота
1. Напиши @BotFather команду `/newapp`
2. Обери свого бота зі списку
3. Вкажи назву гри, опис, завантаж картинку-обкладинку
4. Коли попросить посилання (Web App URL) — встав посилання з Vercel (крок 2, пункт 6)

## Крок 5. Перевір
Відкрий свого бота в Telegram, натисни кнопку меню (або команду з /newapp) — гра відкриється прямо в Telegram.

---

## ⚠️ Важливо: прогрес гравців не зберігається
У цій версії гра тримає весь прогрес тільки в памʼяті браузера — при закритті чи оновленні все обнуляється. Для реального запуску варто додати збереження, наприклад через:
```js
window.Telegram.WebApp.CloudStorage.setItem("save", JSON.stringify(gameState));
```
Якщо хочеш — можу одразу додати збереження прогресу в код, просто напиши.
